# The Plan to Keep Building: Portfolio Growth Strategy

## 1. How to Add the Next Case Study (Systematic Workflow)
To add a new project card without rebuilding or altering portfolio structure, follow this 3-beat template:
1. **Problem Statement:** Briefly outline the technical bottleneck or system issue.
2. **What I Did:** Detail the core AI/ML solution, stack components, and deployment steps.
3. **What Came of It:** State concrete metrics, evaluation results, or functional impact.

---

## 2. Named Next Feature & Set Reminder
- **Next Real Piece of Work:** *Multi-Modal RAG Agent with Local Vector Indexing*.
- **Concrete Reminder Set:** Google Calendar recurring nudge scheduled for every 1st of the month (*"Audit & Add New ML Case Study to Portfolio"*).

---

## 3. Preserved AI Build Context (Claude/Gemini System Prompt)
The system context, style guidelines, tech stack (Python, GitHub Pages, Web APIs), and identity kit are preserved in a dedicated repo file (`skills/README.md`). Future project updates can be generated in minutes by pasting the new case study notes into the existing AI context window.
