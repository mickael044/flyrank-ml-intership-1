# Visual Identity & Visual Framing Audit

## 1. Minimal Visual System (The 3 Choices)
- **Color Palette:** Slate Dark Theme (`#0f172a` primary background, `#1e293b` container cards, `#38bdf8` accent blue for key CTAs and metrics).
- **Typography:** Inter / System Sans-Serif (Clean, high-legibility layout for engineering documentation and mathematical formulas).
- **Layout Spacing:** 8px grid system with high contrast and explicit structural separation (no unnecessary design clutter).

---

## 2. Framing vs. Upstage Rule
- **The Core Rule:** Design must frame the technical proof (code, metrics, model outputs), never upstage it.
- **Implementation:** Background elements are kept dark and minimal so that code blocks, terminal outputs, and benchmark graphs take primary visual precedence.

---

## 3. AI Images vs. Real Screenshots Decision Matrix
- **Real Screenshots (Always Preferred):** Used for Colab execution runs, GitHub repository structure, terminal outputs, and model evaluation charts (`work/figures/`). Real receipts build trust.
- **AI Generated Images (Strictly Limited):** Used solely for subtle hero background abstractions (e.g., stylized network nodes). Rejected all generic hyper-realistic "AI brain" stock art to maintain engineering authenticity.
