## 2. Where Real Captures Beat AI Stand-ins
- **Project Proofs:** Used direct Ubuntu/VSCode/Colab screenshots for code execution instead of AI-generated futuristic dashboards. Real execution traces demonstrate actual technical capability and verifiable work.
